# manzil-invoices
## الحفظ السحابي لحساب واحد (Supabase)

1. أنشئ مشروع Supabase وحساب المالك من Authentication > Users، ثم عطّل تسجيل المستخدمين الجدد من إعدادات المصادقة.
2. في `cloud-schema.sql` استبدل `OWNER_USER_UUID` بمعرّف مستخدم المالك وشغّل SQL مرة واحدة. لا يتطلب ذلك وضع بريدك أو كلمة مرورك في المستودع.
3. من إعدادات التطبيق > الحفظ السحابي، أدخل رابط المشروع ومفتاح publishable أو anon العام. لا تستخدم secret أو service_role.
4. سجّل الدخول بحساب المالك، ثم اختر رفع بيانات الجهاز لأول مرة. على الأجهزة الأخرى اختر تحميل بيانات السحابة.

تعزل سياسات RLS البيانات لحساب المالك المحدد في قاعدة البيانات. تحفظ جلسة الدخول في sessionStorage وتبقى نسخة البيانات محليًا. تُرفع التغييرات المحفوظة أثناء فتح التطبيق، وتمنع أرقام الإصدارات استبدال نسخة أحدث من جهاز آخر. عند التعارض صدّر نسخة محلية قبل تحميل نسخة السحابة. لا تكفي ملفات الواجهة وحدها لتفعيل الخدمة؛ يجب إعداد مشروع Supabase فعليًا. لا يُعد فحص الواجهة بديلًا لاختبار سياسات RLS على المشروع المتصل.
